# AGENTS.md: service-kit/docs

`api-notes.md` records the standards and library behaviour behind the modules: RFC 9457
problem details, the IETF Idempotency-Key draft, the Prometheus text format, CORS, GCRA
token buckets and the cohttp-async notes for the OxCaml switch.

This is plain Markdown, not built by odoc. When a module's behaviour changes, update the
matching section in the same change and name the standard's section number. Keep the
problem codes here consistent with the README table.
